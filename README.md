# 🎨 Generador de Paletas de Colores

Una aplicación web interactiva que genera paletas de colores aleatorias. Perfecta para diseñadores, desarrolladores y creativos que buscan inspiración de color.

## ✨ Características

- **Generación Aleatoria**: Genera 5 colores hexadecimales aleatorios con un clic
- **Bloqueo de Colores**: Bloquea tus colores favoritos y genera nuevos para los demás
- **Atajos de Teclado**: Usa la barra espaciadora para generar paletas rápidamente
- **Copiar al Portapapeles**: Haz clic en el código de color para copiarlo
- **Diseño Responsivo**: Funciona perfectamente en móviles, tablets y escritorio
- **Interfaz Moderna**: Diseño atractivo con animaciones suaves

## 🚀 Cómo Usar

1. Abre `index.html` en tu navegador
2. Presiona la **barra espaciadora** o el botón **"Generar Paleta"**
3. Haz **clic en un color** para bloquearlo/desbloquearlo
4. Haz **clic en el código HEX** para copiarlo al portapapeles
5. Genera nuevas paletas sin perder tus colores bloqueados
